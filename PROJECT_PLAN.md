# Project Plan - Madrasa Management Website

## Goal
Build a complete, dynamic, secure, and responsive website for **ধনুয়া কাচারী পাড়া আহাম্মদীয়া দাখিল মাদ্রাসা**.

## Milestones
1.  **Phase 0: Environment & Setup**
    - [ ] Install PHP & MariaDB in Termux.
    - [ ] Initialize project structure.
2.  **Phase 1: Database & Architecture**
    - [ ] Design and implement MySQL schema.
    - [ ] Setup PDO connection and config templates.
3.  **Phase 2: Homepage & Public Pages**
    - [ ] Homepage with Quran Ayah, Slider, Notice, and Speech sections.
    - [ ] About Us, Administration, Gallery, and Contact pages.
    - [ ] Language Switch (Bangla/English).
4.  **Phase 3: Admin Panel & Authentication**
    - [ ] Multi-role login system (Super Admin, Admin, Teacher, Student).
    - [ ] Admin Dashboard for content management.
5.  **Phase 4: Academic Modules**
    - [ ] Notice System, Classes/Subjects, and Routine.
    - [ ] Online Admission System.
    - [ ] Student & Teacher Management.
6.  **Phase 5: Exam & Library**
    - [ ] Result management and Marksheet generation.
    - [ ] Library management (Books, Issue/Return).
7.  **Phase 6: Testing & Deployment**
    - [ ] Comprehensive testing in Termux.
    - [ ] Manual deployment guide for InfinityFree.
